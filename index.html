v1.9.5 - Polish & Verify Current Build
  • Finish a book and KomiK offers the next volume in the same series, if it is kept on this device.
  • Search the Shelf by title, series or issue number, and filter to books that are on this device.
  • Saved books manager (Settings): see sizes, sort by largest or not read lately, remove one, finished ones, or all.
  • Settings can copy diagnostics (no book names) and shows security policy reports, so problems found on a phone can be reported without a computer. Saving a book that fails now says so.
v1.9.0 - Library & Install Build
  • Books you open can be kept on this device. Tap a book in the Shelf or on the home screen and it opens right away, with no file picking. Remove books one by one or all at once.
  • Install KomiK as an app from the More menu (or Add to Home Screen on iPhone). It can also open .cbz and .cbr files directly on supported desktops.
  • A service worker keeps the app available without a connection after it has loaded once, and offers a Reload prompt when a new version is ready. Settings shows whether offline is ready.
  • The Shelf groups books by series (from ComicInfo.xml) in issue order, with a finished count per series.
  • Settings: keep opened books on this device, group by series, and storage details.
v1.8.0 - Guided View & Reading Polish Build
  • Guided View (beta): detects panels on each page and moves the camera panel by panel. Turn it on from the More menu or with G. Works best on pages with clear gutters; Single mode only.
  • First-time hint with a small page peek. Optional "Previous page like a book" and "Spread: cover page alone" in Settings.
  • Screen stays awake while reading, the browser is asked to keep your data, and storage use is shown in Settings.
  • Browser pinch zoom is available again, and the layout uses the real visible height on phones.
  • Keyboard shortcut list (press ?).
v1.7.1 - iPhone Dock Spacing Build
  • Fixed the empty black strip at the bottom on iPhone: the home-indicator safe area was counted twice (dock position and dock padding).
  • The dock now sits closer to the screen edge while staying clear of the home indicator.
v1.7.0 - Press Green & Reading Comfort Build
  • New visual identity: Press Green with warm neutrals and an ochre bookmark color. Classic Blue is still available in Settings.
  • New app icon (K speech bubble) with proper PNG touch icon. Comic pages now have square corners like the printed page.
  • Settings: page curl on/off, keep zoom between pages, view remembered per book, progress line, tap zone width, swap tap zones.
  • Reads ComicInfo.xml for title, series, number and right-to-left manga.
  • Thin progress line when controls are hidden; the page nudges at the first and last page.
  • Accessibility: labels on all icon buttons, visible focus rings, dialog focus handling, reduce-motion support.
v1.6.1 - Responsive Dock Build
  • Bottom dock now fits any width: icons by default, text labels appear only when there is room. Nothing is cut off or hidden behind a scroll.
  • Less used actions (Fit to width, Export EPUB, About & license) moved into a More menu. Fit to width is now available on phones.
  • Larger touch targets and screen reader labels on dock buttons. Credits moved out of the dock.
v1.6.0 - Trust, Performance & Shelf Build
  • CBR (RAR) now works: bundled extractor runs in a background worker and reads pages on demand. File type is detected from the file itself, not its extension.
  • Home shows Continue reading with the book cover. Shelf has covers, Finished status and Read again.
  • Books are recognized by content, so renaming a file no longer loses progress or bookmarks. Old progress is migrated.
  • Export and import progress and bookmarks as a JSON backup.
  • File names are escaped everywhere (XSS fix). The Offline claim was removed until real offline support arrives.
  • Thumbnails are generated in a worker, progress writes are debounced, and the page curl switches to a lighter look automatically on slow devices.
  • Fixes: reading-time estimate no longer skewed by mode changes, stacked toasts, empty page box.
v1.4.2 - Stability & Memory Build
  • Pages are now decoded on demand with a small cache and next-page preload, so large CBZ files no longer fill memory.
  • Thumbnails and the scrubber preview use small generated images.
  • Button labels (Single / Spread / Webtoon / Bookmark) now show on screens 420px and wider.
  • Webtoon keeps your page when switching modes and handles very tall strips.
  • Spread mode shows wide pages alone and never skips a page.
  • A failed open no longer overwrites the current book's progress.
  • EPUB export: correct image types, pre-paginated layout, real UUID, cover, per-page size and RTL direction.
v1.4.1 - Smarter Zoom & Drag-Drop Build
  • Double-tap the center of the page to zoom 2x at that spot; double-tap again to fit. Side taps always turn pages.
  • Pinch zoom is limited to 1x-4x. Pan can no longer push the page off screen.
  • While zoomed, push past the page edge to turn the page. Side taps are paused.
  • Desktop: Ctrl + scroll (or trackpad pinch) zooms; plain scroll no longer zooms.
  • Drag & drop comic files anywhere on the window.
v1.4.0 - Page Curl & Swipe Build
  • Swipe (touch & mouse drag) to turn pages. The page curl follows your finger and finishes on release or flick.
  • Real page curl with fold, paper back and shadows replaces the old 3D slide. Taps, buttons and keys play it automatically.
  • Works with RTL manga and Spread mode. Respects reduced-motion settings.
